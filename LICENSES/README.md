# Lizenzen in diesem Repo

| Pfad | Lizenz | Warum |
|---|---|---|
| alles ohne eigene Angabe | AGPL-3.0-or-later | Der Code. Schließt die Lücke, dass jemand einen gehosteten Dienst daraus baut, ohne die Quellen offenzulegen. |
| `docs/` | CC BY-SA 4.0 | Texte sind kein Code. Weitergabe unter gleichen Bedingungen, Namensnennung erzwungen. |
| `testdata/`, Beispielmanifeste | MIT | Niemand soll sein eigenes `homelab.yaml` unter AGPL stellen müssen. |
| Name, Logo | keine | Siehe `TRADEMARK.md`. Der Code darf geforkt werden, der Name nicht. |

Diese Grenze muss explizit dastehen, sonst wird sie später bestritten.

`LICENSE` im Wurzelverzeichnis enthält den wörtlichen AGPL-3.0-Text und sonst nichts —
so erkennen ihn Werkzeuge wie GitHub und die Lizenzscanner der Distributionen.

Noch einzusetzen: die wörtlichen Texte von CC BY-SA 4.0 und MIT als Dateien in diesem
Verzeichnis.
