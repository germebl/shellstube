# Glossar

| Begriff | Bedeutung | Nicht sagen |
|---|---|---|
| **Anschluss** | Was vom Anbieter ins Haus kommt | WAN (in Nutzertexten) |
| **Ausbaustufe** | T0 bis T3 | Tier, Level |
| **Bauplan** | Das Ergebnis des Assistenten | Konfiguration, Setup |
| **Einwahl** | PPPoE oder DHCP beim Anbieter | Dial-in, Verbindung |
| **Gültigkeitsdauer** | TTL eines DNS-Eintrags | TTL (beim ersten Mal beides) |
| **Karenz** | Beobachtungszeit für neue Namen | Quarantäne |
| **Knoten** | Ein Gerät im Plan | Node, Host |
| **Manifest** | Die Datei `homelab.yaml` | Config |
| **Runbook** | Die erzeugte Anleitung | Doku (das ist etwas anderes) |
| **Sicherung** | Backup | Backup (in Fließtext) |
| **Strecke** | Der Weg zwischen zwei Geräten | Link, Pfad |
| **Wiederherstellung** | Restore | Restore |

Neue Begriffe kommen **hier** hinein, bevor sie in einer Seite auftauchen.
