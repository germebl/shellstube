# Umgangston

Kurz, weil es kurz sein kann: Sei zu anderen so, wie du selbst behandelt werden möchtest, wenn
du gerade etwas zum ersten Mal machst.

Dieses Projekt richtet sich ausdrücklich an Leute, die bei null anfangen. Wer hier fragt, wie
man ein VLAN einrichtet, bekommt eine Antwort — kein „steht doch im Handbuch". Wer eine dumme
Frage stellt, hat eine Lücke in unserer Dokumentation gefunden.

Nicht in Ordnung: Herabwürdigung, Belästigung, Beleidigungen, das Ausspielen von Wissen gegen
Menschen. Wer das tut, fliegt raus — beim ersten Mal mit Ansage, beim zweiten ohne.

Meldungen an **conduct@shellstube.de**. Wir behandeln sie vertraulich.
